# Мурзик — игра-тамагочи с котиком для малышей

3D-игра в браузере (PWA): кот, которого можно гладить, кормить, купать, укладывать спать, одевать
и играть с ним в мини-игры. Сделана для ребёнка 3 лет: для игры не нужно читать, кнопки крупные,
проиграть и «заболеть» нельзя.

**Играть:** https://mavrodim90.github.io/murzik-game/

Внутри нет рекламы, покупок за реальные деньги, внешних ссылок, аналитики и сетевых запросов
(кроме загрузки самой игры). Звуки синтезируются в браузере, аудиофайлов нет. Запись голоса для
«повторюшки» живёт только в памяти и стирается после воспроизведения.

## Как поставить на главный экран

- **Android (Chrome):** открыть ссылку → ⋮ → «Добавить на гл. экран» (или «Установить приложение»).
- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран Домой».

## Родительские настройки

Маленькая серая шестерёнка вверху по центру: **удерживать 3 секунды**, затем решить пример
(двузначное × однозначное, например 23×4). Там: таймер игры (выкл/10/15/20/30/45 мин),
пауза после таймера (30 мин / 1 час / 2 часа / до завтра), громкость, повтор голоса,
чувствительность микрофона и сброс прогресса (двойное подтверждение).

Когда таймер вышел, Мурзик зевает и засыпает, играть нельзя до конца паузы; обойти можно только
через ту же родительскую проверку (шестерёнка на экране «Мурзик спит»).

## Разработка

```powershell
npm ci
npm run dev          # локальный сервер
npm test             # Vitest: логика (шкалы, экономика, таймер, физика броска, миграции…)
npm run build        # tsc + сборка + проверка бюджета (gzip ≤ 1 МБ)
npm run test:e2e     # Playwright (Pixel 7 + iPhone 13 в эмуляции Chromium), скриншоты в /screenshots
npm run icons        # перегенерировать PNG-иконки из SVG
```

Стек: Vite + TypeScript + three.js (без движков и React), vite-plugin-pwa, Web Audio API.
Все числа (скорость падения шкал, цвета, порог голоса, таймеры) — в `src/config.ts`.
