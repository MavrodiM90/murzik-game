# cinematic-editing

Монтаж = управление тем, **что зритель знает, когда он это узнаёт и что при этом чувствует**. Склейка — решение о подаче информации и времени, а не техническая операция.

## Что скилл не умеет (говори об этом сразу)
- Без видеофайла и таймкодов от пользователя разбор идёт **по описанию**; все таймкоды — ориентиры для сборки, помечай `~`.
- Видео в сессии не воспроизводится. Если файл есть — прогоняй `ffprobe`/сцен-детект/кадры по таймкодам (см. `references/workflows.md`, раздел B). Нет файла — не изображай, что «посмотрел».
- Эффекты (Кулешов и др.) — рабочие эвристики, не законы. Проверка = просмотр результата.

## Порядок работы

1. **Цель.** Одной фразой: что зритель должен *понять*, *почувствовать*, *начать ожидать*. Зафиксируй хронометраж, формат экрана (16:9 / 9:16 / 1:1), платформу, доступный материал. Не хватает данных — задай не более 3 вопросов, остальное прими по умолчанию и назови допущения.
2. **Инвентаризация.** Есть видео → разбери кадры и звук по реальным таймкодам. Есть описание → пометь таймкоды как ориентиры. Всегда раздели на две группы: **ЕСТЬ** (отснято/сгенерировано) и **ДОСНЯТЬ / СГЕНЕРИРОВАТЬ**. Для каждого кадра: крупность, направление движения и взгляда, звук, длительность, что в нём читается.
3. **Основная версия + альтернатива.** Выбери приём по задаче в `references/editing-playbook.md`. Для ключевого момента дай альтернативную склейку и объясни, что она меняет для зрителя (что он знает, когда, с кем он «в одной лодке»).
4. **Монтажный план — таблицей** (формат ниже). Для каждой склейки, где это важно, указывай триггер: движение, взгляд, слово, паузу или звук.
5. **Проверка.** (а) Читается ли действие без звука и без пояснений? (б) Непрерывность: ось, направление, реквизит, свет, костюм. (в) Вовремя ли раскрытие: не раньше, чем зритель успел захотеть узнать, и не позже, чем он потерял интерес. Для AI-кадров отдельно: направление движения и взгляда, положение реквизита, свет, внешность персонажа. Нет нужного плана → предложи замену из имеющегося (перебивка, вставка, звук как мост, смена порядка), только потом — доснять.

Порядок исправления проблем в черновике: **понимание → эмоция/смысл → ритм → непрерывность → звук → полировка**. Не шлифуй звук, пока не ясно, что происходит.

## Формат ответа
1. **Цель и допущения** (3–5 строк).
2. **Инвентаризация**: ЕСТЬ / ДОСНЯТЬ.
3. **Версия A (основная)** — таблица:

| таймкод | кадр и действие | точка склейки | звук | эффект для зрителя |
|---|---|---|---|---|

4. **Версия B (альтернатива ключевого момента)** — только изменившиеся строки + 2–3 предложения «что меняется для зрителя».
5. **Проверка** — чек-лист из шага 5 с отметками и найденными рисками.
6. **Что доснять / сгенерировать** — минимальный набор, приоритет, запасной вариант из имеющегося.
7. Метки уверенности, если опираешься на источник: `[Источник]` — подтверждено автором/изданием; `[Видно/слышно]` — наблюдаемо в кадре; `[Интерпретация]` — моя трактовка.

## Правила честности
- Не приписывай режиссёрам/монтажёрам слова и решения без источника; сомнительное помечай `[Предположение]`.
- Проценты «правила шести» Мёрча — популярный пересказ, не цитата; используй как порядок приоритетов, не как формулу.
- Пока сцена не просмотрена, формулировка «в сцене происходит X» = «по моему описанию/памяти».
