# Рабочие процессы

Общий принцип: сначала **что зритель понимает**, потом **что чувствует**, потом **как быстро**, потом **как звучит**. Приёмы — [editing-playbook.md](editing-playbook.md); кадры — [cinematography.md](cinematography.md); кейсы — [scenes.md](scenes.md).

## A. Сборка сцены из готовых кадров (только список/описание)

1. **Цель** (понять / почувствовать / ожидать). Хронометраж, формат, платформа.
2. **Инвентарь.** Для каждого кадра: ID, крупность, действие, направление движения/взгляда, длительность, звук. Колонки: `ЕСТЬ` / `ДОСНЯТЬ`.
3. **Карта информации.** Что должен знать зритель к концу сцены; в каком кадре он это узнаёт (в версии A и B).
4. **Хребет.** Выбери 3–5 «опорных» склеек (старт, поворот, пик, развязка). Остальное — связки.
5. **Черновая версия.** Порядок кадров и длительности (с запасом по времени ±15%). Таймкоды помечай `~`.
6. **Альтернатива** ключевого момента (сдвиг склейки, перенос звука, добавление/удаление реакции) + «что меняется для зрителя».
7. **Проверка** (см. раздел D).
8. **Таблица плана:**

| таймкод | кадр и действие | точка склейки | звук | эффект для зрителя |
|---|---|---|---|---|

## B. Разбор готового черновика (есть видео)

1. **Технический осмотр:**
   ```bash
   ffprobe -v error -show_entries format=duration:stream=codec_type,width,height,r_frame_rate -of default=nw=1 input.mp4
   ffmpeg -i input.mp4 -vf "select='gt(scene,0.35)',showinfo" -an -f null - 2>&1 | grep pts_time
   ```
   Вторая команда выводит кандидаты на склейки (порог подбирай 0,2–0,5). Покадровые скриншоты: `ffmpeg -ss 00:00:03.2 -i input.mp4 -frames:v 1 f_0003_2.jpg`.
2. **Таймкод-лист склеек:** № | вход | выход | длительность | крупность | что в кадре | звук.
3. **Вопросы к каждой склейке:** читается ли действие? Есть ли причина (движение/взгляд/слово/звук)? Что зритель знает до и после? Нужно ли здесь пауза/реакция?
4. **Симптомы → причина → правка:**

| Симптом | Вероятная причина | Правка |
|---|---|---|
| «Не понимаю, где они» | нет общего, перепутана ось | добавить общий, вернуть ось, обозначить ориентир |
| Провисает | длинные кадры без нового вопроса | укоротить, убрать повтор, уплотнить |
| Дёргается | склейки без мотивировки, скачки | резать по движению/взгляду, увеличить разницу кадров |
| Шутка не смешная | реакция раньше, пауза не там | переставить реакцию, дать паузу до и после |
| Нет напряжения | зритель не знает угрозы | дать угрозу раньше, удлинить ожидание, убрать музыку |
| Эмоция не доходит | нет реакции, поздний крупный | добавить реакцию, ввести крупный раньше |
| Звук «ломает» | акценты не на склейке, нет мостов | J/L-cut, сдвинуть акцент, выровнять уровни |

5. **Порядок исправлений:** понимание → смысл/эмоция → ритм → непрерывность → звук → полировка. Один проход — одна категория.
6. **Результат:** список правок (приоритет высокий/средний/низкий), обновлённая таблица плана, список недостающих кадров.

Если файла нет: не симулируй просмотр; запроси таймкоды/описание или принимай описание как «ориентир».

## C. Планирование съёмки или AI-генерации

1. **Минимальный набор.** Вычисли для каждой склейки, какой кадр *необходим* (без него не поймёт), а какой *желателен*. Составь список (MVP-набор).
2. **Карточка кадра:** ID | назначение в сцене | крупность и угол | действие (старт/конец) | направление | взгляд | реквизит | свет | длительность с запасом | звук | **ЕСТЬ / СНЯТЬ / СГЕНЕРИРОВАТЬ** | запасной вариант.
3. **Для съёмки:** снимай каждое действие с запасом 1–2 с по краям; дубль с паузой; «чистый проход»; тишина 10 с (room tone).
4. **Для AI:** один референс-кадр на сцену (лицо, одежда, свет); промпты строй по шаблону: *субъект + действие + направление + крупность + свет + стиль*; генерируй варианты короткими клипами (3–5 с) по одному кадру; после генерации — проверка по списку в [cinematography.md §6](cinematography.md).
5. **Порядок съёмки/генерации:** сначала кадры хребта (опорные склейки), потом связки, потом перебивки/детали.
6. **Запасной план:** для каждого сложного кадра укажи замену из имеющегося (вставка/деталь/звук вместо плана).

## D. Проверка покрытия и результата

**Хватает ли ракурсов?** Пройди склейки и ответь:
- Есть ли общий для географии? Есть ли ответный кадр для каждого взгляда? Есть ли реакция для каждого ключевого события? Есть ли «выход» (чистый кадр) для эллипсиса?
- Есть ли перебивка для скрытой склейки? Хватает ли запаса по краям?

**Читаемость:** посмотри без звука; кто, где, что делает — понятно? Потом только со звуком (закрыв глаза); ритм и смысл угадываются?

**Непрерывность:** ось, направление движения и взгляда, реквизит, свет, костюм, внешность (для AI — отдельно).

**Раскрытие:** зритель не узнал рано? не слишком поздно? Есть ли момент, когда он хочет узнать, и мы его даём?

**Если плана нет:** из доступного — перебивка, вставка-деталь, реакция другого, звук как мост, переупорядочить, укоротить, добавить текст-плашку (в крайнем случае).

## E. Короткая форма 9:16 (Reels / Shorts / TikTok)

- **Структура:** хук 0–2 с (вопрос/конфликт), развитие, поворот ≈ 60–70% хронометража, финал-связка с призывом.
- **Склейки:** чаще (1,5–3 с на кадр), но пауза перед поворотом (0,5–1,5 с). Звук (шаги, шумы) работает как «ритм-машина».
- **Safe zone:** верх ~10%, низ ~20%, правый край ~10% (кнопки) — без текста и лиц.
- **Субтитры:** по смыслу, не по каждому слову; короткими блоками, читаемыми без звука.
- **Кадр-связка:** кадр, в котором шутка превращается в предложение (экран, предмет, реплика) — планируй заранее.
- **Тест:** смотрит человек без контекста, с выключенным звуком, потом со звуком; понял ли шутку и призыв?
